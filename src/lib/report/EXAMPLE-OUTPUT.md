### Status Badges

```
🟢 CREATE   = New page to create
🔵 OPTIMIZE = Existing page to optimize
🟡 KEEP     = Page is good as-is
```

### Source Badges

```
[COMPETITOR] = Yellow  = From competitor analysis
[SITE]       = Blue    = From your site
[MOZ]        = Green   = From Moz keyword data
[LOCAL]      = Purple  = Location-modified keyword
```
